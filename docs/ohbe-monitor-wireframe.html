3. 任务下发流程

确认方案 → 进入监测 → 下发本轮 →（下一任务 / 自动切换）填充并扇出 → 各窗格执行对话更新。全程 live: false。

1评测页确认

PlanSession 套件 → confirmed_suite。槽位按方案冻结。模式 / 受试 / 参照已定。

2打开监测

加载该 plan_id。目录预告窗格（planned / slot preview）。尚无作业时禁用 Tick。

3下发本轮

显式按钮。复用 POST …/start（live:false）。同一确认套件扇出到本方案全部窗格；打开 Dry-run job。

4切任务 → 填入 → 扇出

「下一任务」或「自动切换任务」：正文填入执行对话并发送/下发给各 harness。C 区追加调度/过程/结果；Tick 揭桩事件。

4. paired_harness vs cross_model（同一壳）

两种模式共用监测壳与下发控件；仅目录行语义与预告来源不同。

P0 · paired_harness（默认）

同一壳 A/B/C

  • 目录行 = Harness（受试 + 参照）
  • 标题 Harness，副标题共享模型
  • pane_id = harness id
  • 下发：同一确认套件 → 两个 Harness 窗格

P1 · cross_model

同一壳 A/B/C

  • 目录行 = 模型（固定一个 Harness）
  • 标题模型，副标题固定 Harness
  • pane_id = model id
  • 作业前：行可来自对比槽预览；作业后切 Dry-run 窗格。槽位 id ≠ 窗格 id 时两边都标
维度paired_harnesscross_model是否同壳
目录主键HarnessModel是 · 仅数据源不同
参数记录字段phase / time / task / model / harness / latency·cost 占位是
执行对话调度 + 过程 + 结果；英文原文保留是
下发显式「下发本轮套件」；任务 one-by-one 扇出是
对比槽编辑不适用主路径仍在评测页 ComparisonSlots监测页只读

5. 已拍板 / 仍待确认

已拍板（本轮反馈）

  • 套件可点开：顶栏「套件详情」展开任务1…任务10（suite 序）；默认折叠。
  • 任务推进：提供「下一任务」按钮 + 「自动切换任务」开关/模式。
  • 切任务行为：任务正文自动填充执行对话框，并发送/下发扇出到各 harness 窗格（不再把「发送」当作纯备注待定）。
  • 顶栏形态：对齐附件 — 方案 · 已确认套件 · paired_harness · 暂停 · 推进 Tick · 下发本轮套件。
  • 壳层：保持左目录 / 右参数+执行对话；Dry-run 诚实性不变；本稿仍为审阅线框，无代码 PR。
